Startup AI Predictor

Project Description

Startup companies face significant challenges in achieving long-term success. Investors and entrepreneurs often rely on financial indicators, market trends, and strategic partnerships to determine whether a startup has the potential to grow.


This project presents a machine learning based system that predicts the success probability of startups. The model analyzes several key parameters including total funding received, number of business relationships, age of the startup during first funding, and average number of participants involved in funding rounds.


The prediction model is trained using historical startup datasets. Using these features, the system estimates the probability of startup success and provides the result as a percentage.


The system is implemented using Python Flask to create a web-based interface where users can easily input startup details and receive instant predictions.
