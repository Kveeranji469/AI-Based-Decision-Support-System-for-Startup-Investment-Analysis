# 🤖 AI-Based Decision Support System for Startup Investment Analysis

An AI/ML-powered web application that helps analyze startup data and support investment decision-making using a trained machine learning model.

## 📌 Overview

This project uses machine learning to analyze startup metrics and provide data-driven insights for investment decisions. It's built as a full-stack web application with a Flask backend serving predictions from a trained model.

## 🛠️ Tech Stack

- **Language:** Python
- **Backend:** Flask
- **Machine Learning:** scikit-learn (model trained and saved as `model.pkl`)
- **Frontend:** HTML, CSS (via `templates/` and `static/`)
- **Data:** Pandas, NumPy
